# AI 主题标签

单盘的命格、感情、事业、财运、健康、性格分别拥有独立对话、追问草稿与生成状态。只有当前标签的消息会显示，也只有该主题自己的最近对话会交给 Codex。

- 首次明确点击没有结果的主题时生成一次；切回已有结果直接展示缓存，不重复调用模型。同一主题内的追问继续追加。
- 生成期间可切换标签，原请求会停止并保留部分结果，晚到的数据不会写到新主题。停止/中断/错误主题可主动重新生成。
- 当前标签、所有主题结果与出处按账号保存。跨设备、刷新和导入恢复不会自动重跑已有内容。
- 点击宫位先查看星曜详情，选择“让 AI 分析这个宫位”后，才按其主要领域进入主题并生成；没有独立主题的宫位沿用当前标签。
- 手机阅读正文 16px，六个带图标主题在上排完整展示，专业/通俗在下排切换；上滑阅读时不强制跟随新内容，显示“有新内容，回到底部”。每个主题保留自己的位置。
- 单盘追问草稿与阅读位置按账号 / 记录保存在此设备当前会话，退出清理；这些草稿不是跨设备历史，不进入 JSON。刷新会保留同一会话的草稿。

## 专业与通俗解读

六个主题和双人合盘都可以切换“专业 / 通俗”。首次选择空白的通俗版时生成一次，之后直接恢复已有结果；不替换专业原文。通俗版默认350–550字，用【先说人话】【放到生活里】【术语翻译】【可以尝试】说明。正文与建议只用日常表达，最多两三个专业词集中翻译，不罗列星曜 / 亮度；生活例子标为假设。短追问不强制重复四节。

请求 `readingMode` 默认 `professional`，通俗版为 `plain`。客户端只提供当前模式 / 主题的历史上下文；通俗版另带同主题已保存专业内容的 `professionalReference`（最多 12,000 字符，含完成状态）。客户端和服务端均移除旧资料编号与出处尾注，该内容只是待解释的不可信参考，当前命盘与本次检索资料优先。专业版未生成时通俗版直接按命盘解释；未完成时不能声称解释了整篇专业内容。仍使用 NAS 内 Codex CLI 和本地资料检索，实时流式输出。

两版消息、生成状态、单盘草稿及阅读位置分别维护；切换会中断当前请求并保留部分结果，晚到文字 / 状态不能污染新模式。草稿规则沿用设备当前会话，合盘草稿仅本次页面内保留。两版结果与当前阅读选择均按账号同步、进入 JSON 备份；换设备不自动重生成。

`topics` 与根 `messages/phase` 始终保留专业语义，新增 `plainTopics`、`readingMode`。合盘专业内容保留在根，另有独立的 `professionalUpdatedAt`，合盘通俗内容仅使用 `plainTopics.overview`。两模式的不同主题按各自时间戳合并；旧客户端不能覆盖已有通俗结构，需刷新后再保存。搜索、档案计数与备份签名包含两版，根专业投影不重复计数。

## 历史兼容

新记录的 `insight.topics` 按主题存储消息、状态和更新时刻；根 `messages/phase` 只反映选中主题。历史与个人档案的解读数量统计全部主题，不重复计算根字段。

旧版本把多个标签混在一份列表。新页面只依据明确的隐藏主题提示词拆分这些记录，普通追问保留在当时主题下；没有明确标记时全部保留在原记录声明的主题中，不猜测或删除文字。迁移不调用 AI。

不同设备更新不同主题时按主题合并；同一主题以其更新时间为准，切换标签不会修改别的主题时钟。服务端拒绝旧页面将已有主题结构降成一份全局对话，避免覆盖其他标签。

## JSON

- v1：原有单盘备份。
- v2：包含合盘而不含独立主题结构的备份。
- v3：包含独立主题结构，可同时包含单盘和合盘。
- v4：启用了通俗模式，完整包含专业与通俗内容。未使用通俗模式的旧记录仍按原版本导出。

新版支持导入四种版本。改变选中标签或更新时间不制造重复备份；任一主题内容变化会作为冲突副本保留。v3 / v4 会完整保存未选中主题与模式，不让旧阅读器误以为只有当前标签。导入上限仍为 20 MB，账号仍共享 1000 条记录上限。


## 图文导览与主题布局

六个图标主题采用等分栅格，与阅读方式分成上下两层；不要恢复移动端60px最小宽度或把模式控件放回同一横排。320px下六主题均可见，模式不覆盖命中区域。

每个主题/模式首个回答前有默认折叠的SVG命盘导览，展开后点选主题宫位、三合与对宫查看保存的主星与生活领域。合盘提供甲乙方独立图示。读取保存快照，不重排、不把图解作为AI额外上下文，不增加模型请求；旧记录、JSON v1–v4和跨设备恢复可直接重建。图解是宫位关系导览，不是AI生成的结论图或预测评分。正文结构标题附辅助图标，原始文字与引用完整保留。
